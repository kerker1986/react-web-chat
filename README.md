# React web chat

## Быстрый запуск

Для запуска проекта вам понадобятся установленные **Node.js** и менеджер пакетов **npm**.

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd ваш-репозиторий
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера для разработки
```bash
npm run dev
```
После запуска проект будет доступен в браузере по адресу: `http://localhost:8080`
